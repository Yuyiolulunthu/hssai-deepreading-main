# 讀伴 ・ 樹狀閱讀 — 部署說明

正式站:`https://hssai-deepreading.phys.nthu.edu.tw`
版控:`github.com/AIFR-Lab/hssai-deepreading`
主機路徑:`/cluster/workspace/hsstuitor/hssai-deepreading`

---

## 一、架構

```
使用者
  ↓ HTTPS
nginx-node (10.0.0.201)          ← 反向代理 + SSL 終止 (certbot)
  ↓ HTTP 10.0.0.101:3060
public-node (10.0.0.101)
  └── Docker: hssai-deepreading  ← php:8.2-apache
        /var/www/html  ← 專案原始碼(唯讀掛載)
        /var/www/html/data ← 執行期資料(可寫)
  ↓ HTTPS
api.anthropic.com / api.perplexity.ai
```

**為什麼用 Apache 容器而不是 nginx 直跑 PHP:** 專案的 `data/` 目錄靠 `.htaccess`(`Require all denied`)阻擋外部讀取,那是 Apache 專屬機制。若改由 nginx 直接跑 php-fpm,`.htaccess` **完全不生效**,`data/school.json`(含學生姓名學號)、`stats.json`、`prompts.json` 會變成可直接下載的公開檔案。用 Apache 容器可完整保留原本的保護,nginx 層再加一道 `deny all` 作為縱深防禦。

## 二、首次上線

### 1. 推上 GitHub

```bash
cd <本專案目錄>
git init
git add -A
git commit -m "讀伴・樹狀閱讀:初始版本"
git branch -M main
git remote add origin git@github.com:AIFR-Lab/hssai-deepreading.git
git push -u origin main
```

> `.gitignore` 已排除 `config.php`(API 金鑰與後台密碼)與 `data/`(學生資料)。
> **推之前確認一次:** `git status --ignored | grep config.php` 應顯示為 ignored。
> 若曾經不慎 commit 過金鑰,務必更換金鑰,而非只做 `git rm`——歷史紀錄仍留有內容。

### 2. 主機取得原始碼

```bash
ssh public                        # 或 ssh <你的帳號>@10.0.0.101
cd /cluster/workspace/hsstuitor
git clone git@github.com:AIFR-Lab/hssai-deepreading.git hssai-deepreading
cd hssai-deepreading
```

### 3. 建立設定檔與資料目錄

```bash
cp config.sample.php config.php
vim config.php          # 填入 ANTHROPIC_API_KEY、三組後台密碼、(選)PERPLEXITY_API_KEY
chmod 600 config.php

mkdir -p deploy/data
# 容器內 Apache 以 www-data(uid 33)執行,需可寫
sudo chown -R 33:33 deploy/data
chmod 750 deploy/data
```

`config.php` 必填項目:

| 常數 | 用途 |
|---|---|
| `ANTHROPIC_API_KEY` | 主對話、導讀、摘要、教師端解析 |
| `TEACHER_PASSWORD` | 教師後台 `teacher.php` |
| `DEV_PASSWORD` | 管理者後台 `dev.php` |
| `SCHOOL_PASSWORD` | 學校後台 `school.php`(預留,不設即停用) |
| `PERPLEXITY_API_KEY` | 簡要查詢(未設定則回退 Anthropic) |

### 4. 啟動容器

```bash
cd /cluster/workspace/hsstuitor/hssai-deepreading/deploy
docker compose up -d --build
docker compose ps
curl -I http://10.0.0.101:3060/            # 應為 200
curl -I http://10.0.0.101:3060/data/stats.json   # 應為 403(保護生效)
```

開機自啟(擇一):compose 的 `restart: unless-stopped` 已足夠;若要納入 systemd 管理:

```bash
sudo cp deploy/dupan-deepreading.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now dupan-deepreading
```

### 5. DNS(兩台都要,zone transfer 目前故障)

在 **phux2** 與 **phux4** 各自新增 A 記錄指向對外 IP,分別驗證:

```bash
dig +short hssai-deepreading.phys.nthu.edu.tw @phux2
dig +short hssai-deepreading.phys.nthu.edu.tw @phux4
```

> phux4 的 negative TTL 為 43200s——若在記錄建立前查詢過,NXDOMAIN 會被快取最長 12 小時。**先建記錄再查詢**。

### 6. nginx 與 SSL

```bash
ssh nginx-node
sudo cp <本專案>/deploy/nginx-hssai-deepreading.conf \
        /etc/nginx/sites-available/hssai-deepreading.phys.nthu.edu.tw
sudo ln -s /etc/nginx/sites-available/hssai-deepreading.phys.nthu.edu.tw \
           /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

sudo certbot --nginx -d hssai-deepreading.phys.nthu.edu.tw
sudo nginx -t && sudo systemctl reload nginx
```

> certbot 會保留設定中既有的 location 區塊,先放好本檔再跑 certbot 是安全的。

### 7. 上線驗收

```bash
curl -I  https://hssai-deepreading.phys.nthu.edu.tw/
curl -sI https://hssai-deepreading.phys.nthu.edu.tw/data/school.json   # 必須 403/404
curl -sI https://hssai-deepreading.phys.nthu.edu.tw/.git/config        # 必須 403/404
curl -sI https://hssai-deepreading.phys.nthu.edu.tw/deploy/docker-compose.yml  # 必須 403/404
```

瀏覽器再走一次:上傳文本 → 導讀生成 → 對話 → 節外生枝 → 匯出;`/teacher.php`、`/dev.php` 登入正常。

## 五、疑難排解

| 症狀 | 檢查 |
|---|---|
| 502 Bad Gateway | `docker compose ps`;`curl -I http://10.0.0.101:3060/` |
| 前台可開、對話報錯 | `config.php` 是否存在、金鑰是否正確;`docker compose logs --tail=50` |
| 後台可登入但存不了 prompt | `deploy/data` 擁有者是否為 uid 33、權限是否可寫 |
| 統計數字沒有增加 | 同上;`data/stats.json` 是否被建立 |
| 憑證到期 | `sudo certbot renew --dry-run`(certbot timer 應已啟用) |

日誌位置:

```bash
docker compose logs -f                                    # 應用
sudo tail -f /var/log/nginx/hssai-deepreading.error.log   # 代理
```

## 七、兩種站台模式

同一份程式碼,由 `config.php` 的 `SITE_MODE` 決定行為:

| | `open` 公開測試版 | `course` 課程正式版 |
|---|---|---|
| 代表站台 | morebeyond.curiouscreate.com | hssai-deepreading.phys.nthu.edu.tw |
| 進入方式 | 直接使用,無需登入 | 邀請碼 + 學號登入(整頁,非彈窗) |
| 文本來源 | 使用者自行上傳 | 只能閱讀教師指定的文本 |
| 自行上傳 | ✅ | ❌(入口隱藏) |
| 教師後台 | 不啟用即可(不給密碼) | ✅ teacher.php |
| 底部 banner | ✅ 問卷連結 | ✅ 問卷連結 |

**切換方式**(改完即生效,不需重啟容器):

```php
define('SITE_MODE', 'course');   // 或 'open'
```

### 課程正式版的完整流程

1. 教師於 `teacher.php` 建立課程 → 取得六碼邀請碼
2. 「📄 指定文本」分頁**上傳文本全文**(可貼上或上傳 .txt/.md/.docx/.pdf),可放多篇
3. 把邀請碼發給學生
4. 學生開站 → 輸入邀請碼、學號、暱稱 → 看到該課程的文本清單 → 點選任一篇開始閱讀
5. 學生的閱讀歷程存在自己的瀏覽器;對話輪數與 token 用量回報到教師後台

> 學生身分僅以「邀請碼 + 學號」驗證,適合課堂情境;邀請碼由教師控制,可隨時重新產生使舊碼失效。

### 公開測試版的部署

同一份程式碼,`SITE_MODE` 設為 `open`,**不要設定 `TEACHER_PASSWORD` 與 `DEV_PASSWORD`**(或設成極強密碼),後台即無法登入。

## 八、階段一解析與閱讀地圖

1. 教師上傳指定文本後,系統**自動**於背景解析(`analyze.php`,教師離開頁面也會完成)
2. 解析 prompt 只由管理者在 `dev.php` 設定,**教師無法調整**
3. 教師審閱並可直接編修解析內容,按「審定儲存」
4. 學生閱讀該文本時,解析會作為「閱讀地圖」注入讀伴的 system prompt——讀伴據此選擇引導方向,但被嚴格要求**不得說出、引述或暗示解析內容**
5. 教師審定後若再修改文本內容,系統不會自動覆蓋審定版,只標示「內容已變更」,由教師決定是否重新解析

儲存位置:`data/analysis/<課程>/<文本>.json`(一篇一檔,不同課程的同名文本互不干擾)

**成本提醒**:閱讀地圖會在每一輪對話都送出(上限約 1.2 萬字),課程學生的每輪輸入 token 會明顯增加。可在 `dev.php` 使用統計的「使用者組成」觀察課程學生的花費變化。

**舊資料**:此功能上線前做過的解析(存於 `data/analysis.json`,以標題為鍵)不會自動轉入。各文本在教師頁面會顯示「尚未解析」,按「開始解析」即可。
